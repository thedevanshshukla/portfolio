# Devansh Shukla — Live AI Systems Lab

A React and Vite portfolio highlighting work in agentic AI, LLM systems, backend engineering, and production-oriented software projects.

## Highlights

- Multi-agent and deterministic AI system case studies
- ZapplyX product and founder-outreach work
- Links to GitHub, LinkedIn, competitive-programming profiles, and live projects
- Motion-rich interface built with Framer Motion and Lucide icons

## Run locally

Requires Node.js.

```bash
npm install
npm run dev
```

Open the local Vite URL printed in the terminal.

## Build for production

```bash
npm run build
npm run preview
```
